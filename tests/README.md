# Проверки проекта

`test_m1_downloader.py` проверяет минутный загрузчик без сети и рабочих баз:
исторический выбор двух контрактов, архивные SECID, пагинацию, проверку OHLCV,
атомарность записи, докачку повреждённых дней, несовпадение торговых и
календарных дат выходных, защиту прежних котировок от пустой перепроверки,
пустые выходные и запуск RTS/MIX.
Дополнительно проверяются произвольный набор активов (`BR`, `Si`, `GOLD`),
независимость от регистра кодов, удаление повторов и отклонение недопустимых
символов в параметре `--assets`. Для новых активов проверяется создание
отдельных баз и правильные метаданные владельца.
Временные SQLite-базы создаются внутри `tests` и удаляются после проверки.
Проверка журналов использует временную папку только внутри `logs` проекта.

Запуск только проверок минутного загрузчика:

```powershell
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -p test_m1_downloader.py -v
```

`test_daily_bars.py` проверяет агрегацию минут в дневные бары: полуоткрытые
границы 21:00, OHLCV, отрицательное тело падающей свечи, фитили и дробные цены,
выбор единственного контракта с экспирацией позже даты окончания интервала,
переход целиком на следующую серию, пустые интервалы и сделки выходного дня.
Проверяются подтверждение загрузки исходных дат, защита от неполных данных,
повторный пересчёт, откат ошибочной записи и запуск RTS/MIX без изменения
исходных файлов. Все базы этих проверок находятся в памяти либо внутри `tests`.

Запуск только проверок дневных баров:

```powershell
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -p test_daily_bars.py -v
```

`verify_daily_databases.py` отдельно сверяет полные рабочие дневные базы с
минутными: независимая группировка по дате начала минуты со сдвигом на три
часа, выбор контракта, набор дат, OHLCV, тело и фитили, число и границы минут.
Оба файла открываются только для чтения, проверяется целостность дневной базы.
Перед сверкой нужно запустить `daily_bars/build_daily_bars.py` за весь доступный
диапазон без `--start` и `--end`. Код `0` означает отсутствие расхождений,
код `1` — ошибку чтения или несовпадение.

```powershell
.\.venv\Scripts\python.exe -X utf8 tests\verify_daily_databases.py
.\.venv\Scripts\python.exe -X utf8 tests\verify_daily_databases.py --assets RTS
.\.venv\Scripts\python.exe -X utf8 tests\verify_daily_databases.py --input-dir C:\data_quote\m1_two_ticker --daily-dir C:\data_quote\d1
```

Запуск из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```
