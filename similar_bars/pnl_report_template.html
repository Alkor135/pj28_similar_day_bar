Показатель
Веса указаны в порядке: тело / верхний фитиль / нижний фитиль / объём. Точность исключает целевые бары с нулевым телом. Средний проигрыш — положительный модуль. Прибыль-фактор — сумма выигрышей, делённая на сумму проигрышей; при отсутствии проигрышей — тире. Просадка рассчитана по закрытиям баров от максимума накопленного PnL, включая начальный ноль. Следующий бар после последнего сигнала может ещё отсутствовать: такой прогноз не включён в итог. Отчёт содержит снимок результатов на момент генерации.
